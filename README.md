## 🇨🇳 中文

这是一个目标管理技能，用来查看和编辑 OKR 周期、目标、关键结果、对齐关系、量化指标和进展记录。创建场景有选择指引，格式说明和 API 资源一并给出，alignments 数据结构也做了说明，让层级关系不再靠猜。文首提供快速决策和推荐优先使用的 shortcuts。它不接管待办任务、日程会议安排和绩效评估。

### ✨ 能做什么

- 查看与编辑 OKR 周期、目标、关键结果
- 维护对齐关系（alignments）与量化指标
- 记录并查看进展更新，追踪目标推进
- 按场景指引选择创建方式，附格式与 API 资源说明
- 优先 Shortcuts 快速路径 + 快速决策表
- 明确不接管待办任务、日程会议与绩效评估

## 🇬🇧 English

A goals skill for viewing and editing OKR periods, objectives, key results, alignments, quantitative metrics, and progress updates. It guides which creation scenario to pick, documents the expected formats and API resources, and explains the alignment data structure so hierarchy stops being guesswork. A quick-decision section and recommended shortcuts open the doc. It stays out of task management, calendar/scheduling, and performance reviews.

### ✨ What it does

- View and edit OKR periods, objectives, and key results
- Maintain alignment links and quantitative metrics
- Log and read progress updates to track goal movement
- Scenario-based creation guidance plus documented formats and API resources
- Shortcuts fast path and a quick-decision table up front
- Explicitly leaves tasks, scheduling, and performance reviews to other skills
